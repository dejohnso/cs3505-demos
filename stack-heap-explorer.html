      Fake addresses are intentionally simple. Stack begins at 0x1000;
      heap begins at 0x4000. Raw integers are displayed in decimal.
      Values that are known addresses are displayed in hexadecimal. An uninitialized pointer slot is shown as 0x????: unknown raw bits, not a defined C++ address value. The address-of operator & is supported,
      but pointer-to-pointer types are intentionally not modeled. The explorer models int& as an alias and supports one two-field Point struct plus one-parameter void functions for comparing values, references, pointers, and C-style arrays. The heap uses a simple first-fit allocator.
      A nested { ... } block creates a local scope whose stack variables disappear at its closing brace.
